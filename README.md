# Python Security Log Analyser

A beginner-friendly cybersecurity project built using Python.

## Project Description

This program analyses sample security logs, counts successful and failed login attempts, and identifies IP addresses with repeated failed login attempts.

## Technologies Used

- Python
- Microsoft Visual Studio
- GitHub

## Features

- Reads sample security log files.
- Counts successful login attempts.
- Counts failed login attempts.
- Identifies IP addresses with repeated failed login attempts.
- Generates a simple security report.

## Project Status

Version 1 completed. Further improvements are planned.

## Disclaimer

This project uses fictional sample security logs for educational purposes.
